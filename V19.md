# AI Film Studio — V19

## Advanced AI Director / Automatic Production Planning

V19 adds a senior production-planning layer above the existing story, scene, shot, continuity and reference systems.

### New capabilities
- Production Blueprint per film
- Target vs planned runtime analysis
- Shot coverage scoring
- Pacing strategy
- Editorial intent
- Hero-shot vs standard-shot classification
- Scene-level objectives and shot strategy
- Production risk flags
- AI Gateway optimization with deterministic fallback
- Re-planning from the project editor

### Design principle
The Director should not merely generate a list of shots. It should decide **why each scene exists, what emotional beat it serves, what coverage is required, and how the final edit should control runtime**.

### Endpoint
`POST /api/director/optimize`

Input: `{ plan }`
Output: `{ plan, blueprint, mode }`

The planner never replaces actual moving video with still-image slideshows.

### Backward compatibility
Projects without a blueprint continue to work exactly as before. V18 reference matching, continuity, QC, regeneration, audio, timeline and render systems remain intact.
