# V26 — UI/UX Polish + Mobile-First Experience

V26 improves the AI Film Studio interface for real production use on desktop, tablet and phone without changing the core production architecture.

## Goals
- Make the studio usable on a phone without horizontal page failure.
- Preserve the professional desktop editor.
- Increase touch target sizes and readable spacing.
- Make dense production controls stack naturally on narrow screens.
- Keep the AI Director chat accessible after the production workspace.
- Respect reduced-motion preferences.
- Preserve existing V22 performance, V23 mastering, V24 production queue and V25 export/YouTube features.

## Mobile behavior
- Desktop sidebar becomes a fixed bottom navigation bar below 900px.
- Project editor changes from two columns to a single-column workflow.
- AI Director chat moves below the main production workspace.
- Production stats collapse to two columns, then remain readable on very small screens.
- Timeline gains horizontal scrolling rather than compressing controls into unusable widths.
- Render/export controls become full-width stacked controls on very small screens.
- Reference library becomes a single-column list on small screens.
- Touch controls receive larger minimum heights.
- Inputs receive visible focus treatment.

## Quality principles
- No photo slideshow substitution: generated footage remains moving video.
- Natural voice remains first-class.
- No change to provider abstractions or rendering architecture.
- No changes to PumpOS.
