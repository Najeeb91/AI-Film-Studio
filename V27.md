# AI Film Studio V27 — Production Deployment, Security & Testing

V27 adds the production-readiness layer while keeping the existing AI Film Studio architecture and PumpOS isolation intact.

## Added
- `/api/health`: operational health check with non-secret dependency status.
- `/api/ready`: explicit production dependency readiness gate.
- `proxy.ts`: security headers including CSP, HSTS in production, frame protection, MIME sniffing protection and permissions policy.
- `lib/security.ts`: timing-safe internal-secret verification, request IDs and request-size guard helper.
- `migrations/001_initial.sql`: deterministic Neon baseline schema plus production indexes.
- `scripts/verify-production.mjs`: required environment configuration check.
- `scripts/smoke-test.mjs`: HTTP smoke test for health/readiness endpoints.

## Production dependencies
AI Gateway, Gemini/Veo, Vercel Blob, Neon Postgres and the independent FFmpeg render worker must be configured before the application is considered production-ready.

## Deployment honesty
V27 does not claim a live deployment. Real credentials, a separate Vercel project, production Blob/Neon resources, and a reachable render worker are required. The existing PumpOS Vercel project is not touched.
