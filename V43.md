# AI Film Studio V43

## Production failure observability + recovery

V43 improves the long-film production queue after the first live test exposed a poor failure UX.

- Production Queue now shows the exact recorded error for failed shots instead of only a generic count.
- Failed shots can be retried from the queue without regenerating completed footage.
- Queueing explicitly resets stale failed-job state in the durable database so retries actually enter the queue.
- Queue start now correctly stops its running state if queue creation fails.
- Production tick returns structured failure details for diagnostics.
- Existing Veo/video-generation architecture is preserved; this version does not fake successful generation.

This release does not claim that a provider configuration/API issue is fixed until the live environment reports a successful generation.
