# V36 — Build Stabilization

This release keeps the V35 feature set and fixes the TypeScript build errors reported by Vercel:

- Video duration is narrowed without Array.includes literal-union inference problems.
- Voice generation response is constructed immutably so optional mediaAssetId is accepted regardless of the inferred provider return shape.
- Reference upload uses a target-compatible data-URI regex.
- Vercel Workflow SDK is not required; render workflow calls the secured render worker directly.
