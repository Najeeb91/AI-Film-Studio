# AI Film Studio V15 — Automatic Regeneration & Continuity Enforcement

V15 closes the visual-QC loop. A generated shot can now be evaluated and, when the multimodal QC recommends regeneration, the AI Director diagnoses the failure, rewrites the shot prompt while preserving story/character/world intent, starts a new moving-video generation, and sends the replacement through the same QC cycle.

## Safety rails
- Maximum 3 automatic regeneration attempts per shot by default.
- Manual `Repair & regenerate` control remains available.
- Failed/uncertain visual analysis does not silently trigger regeneration.
- The original prompt and QC history remain represented through regeneration metadata.

## Flow
Generate → persist → deep visual QC → keep OR repair prompt → regenerate → deep visual QC → keep/review/regenerate (max 3).
