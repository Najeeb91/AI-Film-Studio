# V17 — Reference Image & Character Identity System

V17 makes visual identity references first-class. Character reference images can be uploaded per project, stored durably in Blob, recorded in media_assets, shown in the editor, and automatically supplied to the video generation adapter for shots involving those characters. Up to three active references are sent per generation to stay within provider limits. References are treated as authoritative identity anchors alongside the Character and World Bible.

Flow: upload reference → durable Blob asset → character reference list → continuity selects characters → video adapter downloads/encodes references → provider generation.

If Blob storage is not configured, reference upload is disabled rather than pretending the reference is durable.
