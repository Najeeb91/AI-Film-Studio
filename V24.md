# AI Film Studio — V24

## Full Long-Film Production Pipeline & Parallel Job Engine

V24 turns the existing shot-generation system into a resumable long-film production queue. A film is still composed of real moving-video shots rather than image slideshows.

### Added
- Long-Film Production Queue panel in the project editor.
- Queue every ungenerated shot in a production plan.
- Bounded parallel generation: 1–5 simultaneous provider operations.
- Durable production-job records when Neon is configured.
- Queue/tick API that starts queued shots and polls running Veo operations.
- Automatic video persistence to Vercel Blob when configured.
- Shot-level production status: queued → running → complete/failed.
- Up to three automatic start attempts for transient generation-start failures.
- Priority scheduling for hero shots before standard shots.
- Existing continuity, reference matching, character identity, performance directives and QC remain part of each shot generation request.
- V22 performance/lip-sync planning restored into the V23 audio-mastered source.

### Architecture
The queue is intentionally provider-operation based. The application does not hold an HTTP request open while a video model renders. Each tick checks completed operations, persists finished media, and fills available concurrency slots with new shots. This makes long films resumable and avoids treating a 60-minute film as one generation request.

### Runtime
A 60-minute film remains internally divided into short generated shots. The queue controls generation; the existing timeline/render system remains responsible for editorial assembly and final rendering.

### Important production requirements
- `GEMINI_API_KEY` for real moving-video generation.
- `BLOB_READ_WRITE_TOKEN` for durable generated media.
- `DATABASE_URL` for durable production job records and resumability across browser/device sessions.
