# AI Film Studio V23 — Production Audio Mixing & Mastering

V23 upgrades the audio stage from simple volume mixing to a production-oriented master bus.

## Added
- First-class `AudioMastering` configuration.
- Master target: -14 LUFS integrated for web delivery.
- True-peak ceiling: -1.5 dBTP.
- 48 kHz audio delivery.
- AAC 256 kbps final audio.
- Per-stem gain controls for voice, music and SFX.
- Per-stem fade-in/fade-out processing.
- Dynamic narration ducking for music using FFmpeg `sidechaincompress` instead of static attenuation.
- Configurable duck attack/release.
- Loudness normalization with FFmpeg `loudnorm`.
- Final peak protection with FFmpeg `alimiter`.
- Production Master panel in the project editor.
- `/api/audio/master` endpoint to build a project-aware mastering plan.
- Mastering notes and stem summary are retained in the project plan and render manifest.

## Audio policy
Narration is treated as the primary intelligibility stem. Music dynamically yields to narration. SFX are not automatically ducked because they may be intentional foreground events. The final render applies normalization and peak protection after the stem mix.

## Important limitation
The environment used to package this build does not have the project's npm dependencies installed, so a complete Next.js build could not be executed here. The render worker passes syntax validation with `node --check`.

## Compatibility
V23 preserves V1–V22 data structures. Existing `audioMix` fields remain valid; the new `mastering` object is optional and has sensible defaults.
