# AI Film Studio V22 — Advanced Dialogue, Lip-Sync & Character Performance

V22 adds a first-class character-performance layer without pretending that every video provider natively guarantees perfect lip-sync.

## Added
- `ShotPerformance` and `DialoguePerformance` schemas.
- Per-shot performance planning: mode, blocking, eye-line, facial expression, body language and performance prompt.
- Dialogue lines tied to character IDs and voice identity.
- Performance-aware video prompting; generated shots receive the performance directive automatically.
- Optional external lip-sync adapter at `/api/performance/lipsync` using `LIPSYNC_API_URL` and `LIPSYNC_API_KEY`.
- Graceful `unsupported` response when no lip-sync provider is configured rather than falsely claiming synchronization.
- Project editor controls to build a performance plan and enter dialogue/emotion per character.
- Existing V17–V21 continuity, references, QC, regeneration, timeline and rendering remain intact.

## Quality rule
V22 separates **performance planning**, **dialogue audio**, and **lip-sync rendering**. A provider must explicitly be configured for actual lip-sync processing. The system never labels a shot lip-synced merely because dialogue exists.
