# AI Film Studio — V42

V42 fixes production project persistence behavior discovered during the first live Vercel test.

## Changes
- Production project creation/list/read/update now requires `DATABASE_URL`.
- Production no longer falls back to `data/projects.json`, which is not durable on Vercel serverless runtimes.
- Database initialization failures return explicit `503` responses with actionable error messages.
- Create Film UI now surfaces the actual persistence error instead of the generic “Plan created but could not be saved.” message.
- Media/project persistence also refuses the filesystem fallback in production.
- Local development may still use the JSON fallback when `NODE_ENV` is not production and `DATABASE_URL` is absent.
- No PumpOS code or project is touched.

## Required Vercel production variable
`DATABASE_URL` must be set on the AI Film Studio Vercel project. Once present, the existing automatic database initialization creates the required Film Studio tables.
