# V18 — Shot Reference & Visual Matching Engine

V18 makes visual references a first-class production asset rather than a character-only feature.

## Added
- Project reference library with types: character, location, prop, costume, architecture, artifact, visual.
- Durable Blob-backed reference upload and media-asset records.
- Backward-compatible character identity references.
- Shot reference manifests with priority, role, reason, source and inclusion state.
- Automatic shot-aware reference matching using scene, shot, continuity, world and reference metadata.
- Provider cap enforcement: maximum three selected reference images are sent to the current Veo adapter.
- Manual include/exclude controls at shot level.
- Continuity state now records matched reference IDs.
- Video generation consumes the shot manifest first and falls back to V17 character references when no manifest exists.
- Reference IDs used are returned by the video-generation API for traceability.
- Reference library and shot-level reference UI.

## Design principle
The Director chooses evidence for each shot. The system does not blindly send every project image to the video model. Identity anchors, location/architecture evidence, props, costumes and visual-style references are ranked and capped according to provider limits.

## Compatibility
V17 character reference data remains valid. Character uploads now also register a project-level reference so the V18 matcher can reuse them.

## Not deployed
This build is packaged locally. PumpOS was not modified and no Vercel deployment was performed.
