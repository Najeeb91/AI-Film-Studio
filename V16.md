# V16 — Character & World Continuity Engine

V16 makes continuity a first-class production system rather than prompt-only context.

## Added
- `ContinuityState` on every shot.
- Character identity locks and wardrobe extraction.
- Location/world locks.
- Time-of-day and visual-style locks.
- Recurring-prop detection from scene purpose.
- Previous-shot relationship tracking.
- Canonical continuity prompt generated per shot.
- `/api/continuity` for creating, enforcing and reporting continuity state.
- Video generation automatically enforces continuity when project/shot coordinates are supplied.
- Project UI exposes a **Lock continuity** control and displays active locks.

## Principle
Every generated shot receives a deterministic continuity context derived from the current project bible, scene, and preceding shot. A generation should not silently change established identity, wardrobe, location, lighting/time progression, or recurring props.

This is intentionally complementary to V15 visual QC: continuity state defines what should remain consistent; visual QC determines whether the actual footage appears to respect it.
