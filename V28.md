# AI Film Studio V28 — Production Operations & Deployment Kit

V28 turns the production-ready codebase into an operationally deployable package without touching the existing PumpOS Vercel project.

## Added
- Protected `/api/ops/status` with production/render job counts and failure counts.
- Request IDs on operations responses.
- Stronger readiness gate requiring `RENDER_WORKER_SECRET`.
- `scripts/preflight.mjs` and `npm run preflight`.
- Docker image definition for the independent FFmpeg render worker.
- `docker-compose.worker.yml` for repeatable worker deployment.
- V28 version reporting.

## Boundary
The web application and FFmpeg worker remain separate services. The existing PumpOS Vercel project is not used for AI Film Studio.

## Current deployment status
A dedicated Vercel project, Neon database, Blob store, provider credentials, and reachable render worker are still required before a real production deployment can pass the preflight gate.
