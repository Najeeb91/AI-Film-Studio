# V14 — True Visual Quality Control & Continuity Review

V14 upgrades QC from prompt heuristics to actual footage analysis.

## Deep Visual QC
For completed generated shots:
1. Download the durable video URI.
2. Extract representative frames with FFmpeg.
3. Send the frames plus shot/scene/character/world context to a multimodal vision model through AI Gateway.
4. Score visible quality and continuity.
5. Recommend keep, review, or regenerate.

Checks include:
- character identity/appearance consistency
- environment/location consistency
- temporal consistency/flicker
- realism and anatomy
- composition
- motion quality
- visual artifacts
- prompt-to-footage compliance

## Fallback
If footage, FFmpeg, or multimodal configuration is unavailable, the existing heuristic QC remains available and explicitly marks the result as `heuristic-fallback` and `reviewRequired`.

## Product rule
A shot should never be marked production-ready solely because its prompt looks good. Completed footage must be visually reviewed when deep QC is available.
